THE CRIMSON ARCHIVE — UPDATED EDITION

HOW TO OPEN
1. Extract the ZIP file.
2. Open the Prince_Crimson_Archive folder.
3. Double-click index.html. It opens in your browser.
4. Internet is only needed for the optional Google Fonts; the website itself works offline.

WHAT'S NEW
- New dashboard-style layout with a sticky navigation sidebar.
- Expanded profile, interests, field notes, and IT learning sections.
- Three interactive activities: Rune Recall, Arcane Reflex, and Keeper's Questions.
- Trial progress bar, earned seals, reset button, live clock, and light/dark theme toggle.
- Responsive layout for phones and desktop screens.

PERSONAL PHOTO
The current my-photo.svg is a placeholder. Replace it with your own image and either:
- Rename your image to my-photo.svg only if it is actually an SVG file, or
- Update the image filename in index.html (the img inside .portrait-frame) to match your photo, e.g. my-photo.jpg.

EDITING
- index.html = website content
- style.css = layout, colors, and visual design
- script.js = games and interactions

The 45-second goal is handled through optional exploration and activities, not a forced timer or waiting screen. Visitors can move around freely.


NEW IN THIS VERSION
- Three interactive archive rooms with changing records.
- Three hidden sigils to find around the page.
- Three existing mini activities in the Keeper's Trial.
- The code uses regular HTML, CSS, and JavaScript with simple functions and event listeners.

STUDENT NOTE
You can explain the project using these ideas: HTML builds the sections and buttons, CSS controls the layout and appearance, and JavaScript responds when a button is clicked. The room buttons change the displayed text, while the hidden sigils use a Set to avoid counting the same one twice.
