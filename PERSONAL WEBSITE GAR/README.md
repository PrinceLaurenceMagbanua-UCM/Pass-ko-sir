# Prince.exe — Personal Website

A one-page personal website made with HTML, CSS, and JavaScript.

## Files
- `index.html` contains the page content and structure.
- `style.css` contains the design, responsive layout, and animations.
- `script.js` controls the theme switch, interest dialogs, side-quest progress, vibe picker, surprise button, and scroll progress.
- `my-photo.jpg` is the portrait used on the page.

## Run it
Keep all four files in the same folder and open `index.html` in a browser. No installation is required. An internet connection loads the selected Google Fonts; local fallback fonts are used offline.

## Features
- Responsive design with animated portrait framing
- Sticky navigation and scroll progress indicator
- Dark and light themes
- Random-message surprise button
- Four clickable interest cards with detail dialogs
- Side-quest progress that updates as cards are explored
- Interactive vibe picker
- Scroll reveal animations and reduced-motion support
